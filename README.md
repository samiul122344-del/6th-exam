# FitLog - Gym Companion App

FitLog is a dark-themed, modern gym companion web application built with Next.js and Tailwind CSS. It helps users explore workout libraries, plan their daily routines, and save their favorite exercises.

## 🚀 Features

- **Workout Library:** Browse various exercises categorized by muscle groups with details (duration, calories, rating).
- **Today's Plan:** Easily add or remove exercises to build your daily workout routine.
- **Saved Workouts:** Bookmark workouts for quick reference later.
- **Responsive & Dark UI:** Designed with a sleek, dark aesthetic inspired by modern fitness tracking apps.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **State Management:** React Context API (`PlanContext`)
